# sports-competition-db

Лабораторная работа: даталогическая модель базы данных «Спортивные соревнования».

## Описание

База данных предназначена для учёта:
* городов, спортивных объектов и организаций;
* соревнований, участников и результатов;
* судей, их ролей и назначений.

## Структура

В репозитории представлены:
* `schema_sports_db.sql` — полный SQL‑код создания БД с комментариями и ограничениями целостности.
* `erd_sports_db.png` — ERD‑диаграмма (даталогическая модель).

## Особенности реализации

* **Целостность данных**: реализованы внешние ключи (FK) с `ON UPDATE CASCADE` и `ON DELETE RESTRICT/CASCADE`.
* **Проверка корректности**: ограничения `CHECK` на даты, время, пол и занятые места.
* **Автоинкремент**: все первичные ключи — `SERIAL`.

## Как развернуть базу

1. Установите PostgreSQL и pgAdmin (или используйте консоль).
2. Откройте `schema_sports_db.sql` в Query Tool (или откройте sports_competition_db.pgerd).
3. Выполните весь скрипт (F5).
